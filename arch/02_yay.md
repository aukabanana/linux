| **Command**               | **Task**                         |
| ------------------------- | -------------------------------- |
| `yay` or `yay -Syu`       | **Sync/Update All** (Repo + AUR) |
| `yay -S <package_name>`   | **Install a package**            |
| `yay -Ss <search_term>`   | **Search for a package**         |
| `yay -R <package_name>`   | **Remove a package**             |
| `yay -Rns <package_name>` | **Remove w/ dependencies**       |
| `yay -Sua`                | **Update only AUR packages**     |
| `yay -Yc`                 | **Remove unused dependencies**   |
