
| Shortcut           | Do                |
| :----------------- | :---------------- |
| `Alt + \`          | Go to top         |
| `Alt + /`          | Go to bottom      |
| `ALT + A`          | Set mark          |
| `ALT + T`          | Cut all from mark |
| `ALT + U`          | Undo              |
| `ALT + E`          | Redo              |
| `ALT + R`          | Replace           |
| `Ctrl + W`         | Search            |
| `Ctrl + _`         | Go to line        |
| `Ctrl + K`         | Cut/Delete        |
| `Ctrl + O` , enter | Write out         |
| `Ctrl + X`         | Exit              |
